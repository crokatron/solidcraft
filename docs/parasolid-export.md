# Parasolid text export

File > Export > Parasolid writes an independent `.x_t` text file. STEP and Parasolid export open a body-selection panel before asking for the destination. Current CAD selections are used first; otherwise visible CAD bodies are selected. Reference scan meshes are excluded, and the panel offers all/visible CAD body choices. The body context-menu Export picker also offers `.x_t`. Programmatic use: `file.export` with an `.x_t` path or `format: "x_t"`; pass `bodies: ["Body name"]` to export a subset. The MCP export tool accepts `x_t`.

The writer preserves separate, placed closed CAD solids. It transfers bounded planes, analytic carriers and exact B-spline/rational B-spline geometry, shared edges and vertices, and the original parameter-space trimming curves. Source edge and vertex tolerances are retained; trimmed-curve endpoints are evaluated on their own carriers rather than replaced with nearby topological vertex coordinates. Existing exact NURBS forms take precedence over analytic labels so their trim parameterization is retained. Geometry coordinates are converted from millimetres to XT metres; spline knot parameters and weights remain unchanged. It does not tessellate.

Whole-design assembly export writes actual XT ASSEMBLY and INSTANCE records and standard part/instance name attributes. Component occurrences retain their grouping, including multi-body components. Geometry is baked into world placement and instances use identity transforms: repeated occurrences are distinct placed definitions. Parametric features, constraints, mates, appearances and shared-definition associativity are not transmitted. Selected-body export is a collection of independent bodies, not a reconstructed component tree.

Closed solids with an outer boundary and enclosed cavity shells preserve their material and bounded void regions. Unsupported procedural geometry without an exact NURBS form, scan meshes, open sheets, non-manifold boundaries, bodies with multiple material regions and collapsed pole boundaries are refused before a file is written. Binary `.x_b` and native NX `.prt` writing are not implemented.

The serializer uses the public [UGS Parasolid XT Format Reference, October 2006](https://www.13thmonkey.org/documentation/CAD/Parasolid-XT-format-reference.pdf) and schema 13006. It needs no NX or Parasolid installation. The independent decoder accepts all 13 placed CAD bodies of the Doorbell System test assembly: 812 faces and 2,122 edges, with no reported new geometric approximation. A separate typed-node audit checks all 4,244 fin links, both region sides, boundary geometry chains and geometric-owner rings, plus the five assembly containers and 17 instance links. Kernel reimport keeps all 13 bodies closed, with identical face/edge counts and maximum vertex-bound drift below 3e-14 mm. The largest relative volume difference is 5.44e-7 (the original part has 0.01 mm tolerances). Commercial Parasolid/NX interoperability has not been certified; the target application's file-open versus import behavior can affect assembly handling.
